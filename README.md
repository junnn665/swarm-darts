# SWARM DARTS 🎯

**中濱Games** のブラウザゲーム。

ダーツの群れになって巨大ボードへ突っ込め！
ゲートをくぐって本数を増やし、最後は群れごとボードのど真ん中に突き刺してスコアを稼ぐ 3D ゲームです。
友だちと **みんなで対戦** もできます。

## 遊び方（ひとりで）
- 👆 上下左右スワイプ（PCは ← → ↑ ↓ / WASD）で、上下左右 4 つのゲートから選んで本数アップ
- 🟥 赤いゲートで本数が減る。紫のゲートは群れの広がりが変わる。トゲのローラー（床・空中）や、上下に動くバーに当たっても減る
- 🎯 ボードが見えたら上下左右で狙いを定める
- 目標スコアを超えたら次のステージへ。目指せ 100億点！

### ボードのボーナス（ブル以外も狙える）
| ボーナス | 内容 | 出るステージ |
| --- | --- | --- |
| ✨ 光る数字 | その数字に刺さると ×3（序盤）／×5／×10（ステージ7〜）。小さい数字でも最低10点扱い | ずっと |
| ⭐ 回る星 | ボードを回る星に刺さると ×5。ボードが見えてから回り始める | ステージ2〜 |
| 🟣 ワイド／ギュッ | 紫のゲート。群れが広がる／まとまる（本数は変わらない） | ステージ2〜 |
| 🌈 ばらまき | 当たった数字が 10種で ×1.5、15種で ×2.5、20種ぜんぶで ×3（全体にかかる） | ずっと |
| 💀 ドクロ | 刺さると 1本 -100点。1つめは光る数字の通り道に置かれる | ステージ3〜（最大3つ） |

安全にブルを狙うか、ギュッで固めて光る数字に賭けるか、ワイドで広げてばらまきを狙うか。
対戦では全員に同じボーナスが出ます。

## みんなで対戦（通信）
1. ひとりが「👥 部屋を作る」→ 4ケタの部屋番号・招待リンク・QR が出る
2. ほかの人は「🔢 番号で参加」か、リンク／QR から参加（何人でも OK。色分けは 8 人まで）
3. ホストがむずかしさ（かんたん／ふつう／むずかしい／鬼）を選んで「スタート」→ 3・2・1 でいっせいに開始
4. 全員 **同じコース**。相手の群れは半透明の「ゴースト」で見えて、左上に本数の順位が出る
5. **おじゃま**：×4 以上のゲートを通ると、ほかの全員の前に紫のトゲが飛んでいく
6. 走っている間も結果画面でも **スタンプ**（👍 😂 😱 🔥 ナイス まだまだ）を送れる
7. 全員ゴールしたらスコア順に順位発表。ホストが「もう一回」で次の対戦、「むずかしさを変える」で待合室へ

- 途中で入った人は次の回から参加。ホストが抜けると、次に早く入った人がホストになる

通信は「都道府県ゲーム」「おでこでお題当て」と同じ Firebase Realtime Database（`odeko-ddb38`）を使っています。
データは `rooms/darts-<部屋番号>` に入るので、ほかのゲームの部屋とはぶつかりません。
作ってから 24 時間たった対戦部屋は、次に部屋を作ったときに自動で消えます。

## ホーム画面に追加
iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、アイコン付きのアプリのように全画面で遊べます。

## 公開方法（GitHub Pages）
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
数分後に `https://junnn665.github.io/swarm-darts/` で遊べます。

## ファイル構成
| パス | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面とデザイン |
| `main.js` | ゲーム本体（3D 描画・コース・群れ・ゴースト） |
| `net.js` | みんなで対戦（部屋・参加・おじゃま・スタンプ・順位） |
| `lib/qrcode.min.js` | 招待 QR（qrcode-generator, MIT） |
| `icons/` / `manifest.webmanifest` | ホーム画面用アイコン |

[Three.js](https://threejs.org/) を CDN から読み込んでいるので、ビルド不要の静的ファイルだけで動きます。
