# SWARM DARTS 🎯

**中濱Games** のブラウザゲーム。

ダーツの群れになって巨大ボードへ突っ込め！
青いゲートをくぐって本数を増やし、最後は群れごとボードのど真ん中に突き刺してスコアを稼ぐ 3D ゲームです。

## 遊び方
- 👆 左右スワイプ（PCは ← → / A D）で青いゲートを選んで本数アップ
- 🟥 動く赤いブロックに当たると本数が減る
- 🎯 ボードが見えたら上下左右（↑ ↓ / W S も可）で狙いを定める
- 目標スコアを超えたら次のステージへ。目指せ 100億点！

## 公開方法（GitHub Pages）
Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
数分後に `https://junnn665.github.io/swarm-darts/` で遊べます。

## 技術
- [Three.js](https://threejs.org/)（CDN 読み込み、ビルド不要）
- HTML / CSS / JavaScript のみ
